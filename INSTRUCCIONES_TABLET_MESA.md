# Tablet + mesa touch

La maqueta ahora está configurada para sincronizarse por **Firebase Realtime Database**, es decir, por internet.

Usa la guía principal:

```text
INSTRUCCIONES_FIREBASE.md
```

URLs esperadas después de desplegar en Firebase Hosting:

```text
Mesa touch: https://f1-sap.web.app/display
Tablet:     https://f1-sap.web.app/controller
```

El archivo clave que debes completar es:

```text
firebase-config.js
```
